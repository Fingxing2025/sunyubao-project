# Sunyu Baobao · Codex 桌宠

根据工作目录的人像照片制作，保留黑色短发、眼镜、深蓝拼色上衣，采用圆润的 Q 版 3D 玩偶风格。原始照片未修改。

## 在本机启用

桌宠文件已经安装到 `~/.codex/pets/sunyu-baobao/`。

1. 打开 Codex 设置，找到「宠物」或「Mini」。
2. 在自定义宠物区域点击「刷新」，选择「Sunyu Baobao」。
3. 点击「唤醒虚拟宠物」或「显示 Mini」。

如果刷新后仍未出现，可在方便时重新打开 Codex，再进入宠物设置。

当前电脑控制工具禁止操作 Codex 自身界面，因此已完成文件安装与动画预览验证，尚未代为选中或唤醒桌宠。

## 文件

- `桌宠预览.html`：双击即可离线打开，无需安装依赖。可切换九种动作、暂停/继续、切换深浅背景。
- `Sunyu-Baobao-Codex桌宠.zip`：可迁移安装包。解压后把整个 `sunyu-baobao` 文件夹放入另一台电脑的 Codex 用户目录下的 `pets` 文件夹。
- `final/pet.json` 与 `final/spritesheet.webp`：原生桌宠包。
- `qa/contact-sheet.png`：所有动作帧总览。
- `qa/previews/`：九组循环 GIF。
- `final/validation.json`、`qa/review.json`、`qa/run-summary.json`：格式、逐帧、交付检查记录。
- `生成提示词.md`：人物和动作的生成规格。
- `references/canonical-base.png`：统一角色原画，用于后续保持外貌一致。

## 制作与验证

2026-09-14 使用内置 `image_gen` 生成统一角色原画及八组动作图；左跑由通过检查的右跑逐帧镜像得到，帧序保持不变。没有使用外部图片 API 或历史 IskUnion 路径。

使用 Hatch Pet 的提取、拼图和校验脚本输出透明 WebP。根据首轮视觉检查，将逐帧缩放改为 `stable-slots` 的逐行共同尺度，保留跳跃高度与低头动作；蓝色背景提取阈值为 150。相关提示词见 `生成提示词.md`。

最终图集使用 Codex 支持的 v1 格式：1536 × 1872 像素，8 列 × 9 行，每格 192 × 208，共 57 个有效帧。15 个未使用格全透明，透明像素 RGB 残留为 0。格式检查与逐帧检查均无错误；逐帧报告中的 `stable-slots` 提示已结合图集和浏览器动画检查。

已验证：本机安装副本与交付文件哈希一致；预览 HTTP 200；九个动作按钮映射正确；九组动画均发生帧变化；暂停后帧号保持不变；恢复播放与深浅背景切换正常；浏览器未记录警告或错误。已检查全帧总览中的人物一致性、完整身体和运动方向。
